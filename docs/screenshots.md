# 文档截图维护

当前配图于 **2026-10-15** 从已安装的 **AI Toolkit v2.0.0 macOS 桌面应用**实际窗口截取，使用浅色外观。原始窗口为 2400 × 1600 像素，发布图片统一为 1800 × 1200 PNG。

## 重新截图

1. 使用当前版本的桌面应用；从源码启动时运行 `pnpm tauri:dev`。浏览器中的运行时提示页不能用作软件截图。
2. 保持相同窗口尺寸与外观，等待列表、动画和弹窗完全加载后截图。弹窗可展示内置示例，截图后取消，不保存示例配置。
3. 优先展示公共 Skills 和不含凭据的配置摘要。只做页面切换与筛选，不为截图执行同步、积分领取、推理、账户导入或设置保存。
4. 检查昵称、用户名、邮箱、手机号、账号 ID、设备标识、本机用户目录、请求记录、Token、API Key、配置命令和环境变量。所有可见敏感内容使用不透明色块完整覆盖；不要仅模糊、半透明覆盖或保留可还原图层。
5. 扁平化导出 PNG，移除元数据，检查缩放后的边缘没有漏字。原始截图仅临时保存在仓库外，验证完成后删除；仓库只保留打码后的图片。
6. 将最终 PNG 原样复制到官网，保持两处文件内容一致，同时核对中英文 README、官网首页、功能、亮点、更新页以及 `scripts/sync-changelog.mjs` 中的引用和说明。

截图中的余额、工具数量、模型目录与连接状态是当时的本机状态，不代表所有用户拥有相同额度或模型权限。API Key 区域只展示应用默认的提示文字，不复制或显示实际密钥。
